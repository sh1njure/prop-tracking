# Prop Ledger

Личный учёт проп-аккаунтов: покупки, статусы, выплаты, итог и ROI.

Статический сайт (GitHub Pages) + Supabase (вход по email, Row Level Security: каждый видит только свои записи).
Ключ в app.js — публикуемый (publishable), он безопасен в браузере; доступ к данным ограничен политиками RLS.
